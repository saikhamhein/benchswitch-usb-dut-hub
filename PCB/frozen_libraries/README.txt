Frozen library definitions for this design

Only the symbol and footprint definitions used by the reviewed design are included. Project-local library entries deliberately bind these names to the frozen copies, avoiding unintended changes when opening the project with KiCad 10.0.6.

Do not bulk-update the existing footprints or symbols from new global libraries merely to migrate file formats. When adding new parts, extend these frozen libraries deliberately or use a separate library name. The complete standard catalog is not included here.

Native board geometry and embedded schematic symbols remain authoritative. The applicable KiCad library copyright and license notices are included alongside these files.
