# Nominal component models

These drawing-derived models represent R5-LCSC component packages and terminal datums. Cosmetic features, internal connector contacts and production markings are simplified. They are not manufacturer-certified CAD or maximum-clearance envelopes.

The public PCB retains its circuit, copper, placement and selected parts. Optional Phoenix and Wurth vendor visuals were omitted from this release because redistribution rights were not established. This affects the 3D view only: the Phoenix input terminal and four ordered XUNPU USB-A connectors remain in the PCB and BOM.

Use purchased-part dimensions and the build/bring-up requirements for physical checks. See [third-party notes](../../../doc/THIRD_PARTY.md).
